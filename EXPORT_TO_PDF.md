# Export dashboard to PDF

## Quick method (recommended)

1. **Open the dashboard**  
   Double-click `vibe_funnel_admins_prompt_effect.html` or open it in Chrome/Safari/Firefox.

2. **Print to PDF**  
   - **Mac:** `Cmd + P` (or File → Print)  
   - **Windows:** `Ctrl + P`

3. **Save as PDF**  
   - Set **Destination** to **Save as PDF** (Chrome) or **PDF → Save as PDF** (Safari).  
   - Optionally enable **Background graphics** so the dark theme and chart colors are included.  
   - Click **Save** and choose a location.

The page already has print styles so the layout and colors should look good in the PDF.

## Optional: Fit to one width

In the print dialog you can set **Scale** or **Layout** (e.g. “Fit to page” or 100%) so the full width fits on the page.
