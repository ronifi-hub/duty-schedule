Framing

Why this matters

  • Trial design drives activation, time-to-aha, and conversion in a crowded category.
  • Norms are shifting: credits, grace periods, bundled AI — not only classic 14-day trials.
  • Internal tension: account-level AI credits shared across features can block users from ever running agents after they invest in setup.
Question for the deck: Are we optimizing for adoption (freemium/grace) or revenue alignment (consumption) — and where do agents sit?

Market signals

Six trends

  • Per-seat → usage — cost tracks value delivered (SF, Zendesk, Intercom).
  • Credits are universal — shared vocabulary across competitors.
  • Self-serve is table stakes — ServiceNow is the outlier.
  • Grace periods = new trial — ship free, announce billing later.
  • AI bundled into plans — agents not always a separate SKU.
  • Aha before paywall — best trials prove value before money.

Implications for monday.com

Opportunities

  • Notion-style grace + comms — same category bar.
  • Bundled credits feel standard — reduces separate “agent SKU” friction.
  • Outcome-based pricing unclaimed in WM if we define a unit.

Risks

  • Generosity expectations — shorter free window feels stingy.
  • Stacking agent $ on seat $ — total cost barrier.
  • Billing cliff — abrupt cutoffs; Notion’s graceful pause is the reference.

Insights

What works vs what fails

Works

  • Describe intent → agent configures itself
  • Value inline in primary surface
  • Preview / dry run before live
  • Usage visible from day one

Fails

  • Long prerequisite chains
  • Blank builder, no first use case
  • Async-only aha in short trials
  • Hard cutoff when credits end

Recommendations

Six UX principles for monday Agents trial

  1. Describe, don’t configure — conversational setup.
  2. Inline value — outputs on boards/items, not only admin UI.
  3. Dry run — preview before real execution.
  4. Suggested first agent — no empty state.
  5. Never interrupt active work — pause at boundary.
  6. Transparent usage — credits/dashboard during trial.

monday draft · platform-agents-trial-flow.md

Problem & proposed solution

  • Problem: Shared account AI credits — users may exhaust them on other AI, then hit a wall at Activate after full agent setup.
  • Proposal: Dedicated agent trial — 1,000 credits · 30 days · account-level — gated at execution (Activate / Run now), not during setup.
  • Rationale: Sunk setup + curiosity → higher trial start; separate pool guarantees exposure to agents.

monday flow

End-to-end (draft)

Agent setup (no gate)
    → User clicks "Activate" or "Run now"
        → Trial Start Modal ("Unlock Platform Agents" · 1K credits · 30d · no CC)
            → Trial active: indicator + activity dashboard + warnings at 80% / 100%
                → End-of-trial modal (value summary / performance review)
                    → Graceful pause: finish current runs, preserve config, read-only dashboard

Post-trial behavior explicitly aligned with Notion-style graceful pause, not Base44-style hard stop.
